          Theme

          To choose a theme manually, turn auto-switch off.

          A theme without data (no city set, no picture uploaded, no countdown date) is skipped.

          Brightness

          Tick "Invert backlight" if the screen stays black, or if brightness works backwards.

          Night mode

          Uses the time of the clock (see Time). The window may cross midnight.

          Password

          Asked by the browser for this page, the API and firmware updates (user name: admin). It is sent in clear text over plain HTTP, so it keeps casual visitors out of your settings; it is not protection against someone who can listen to your network.

          Rescue mode is never password-protected, so a firmware update stays possible whatever happens. If you forget the password: switch your router off (or take the device out of its range) until the Status-ESP hotspot appears on the device, connect to it, open http://192.168.4.1 and remove the password here (or do a factory reset). The device opens the hotspot by itself after its Wi-Fi attempts fail.

          Back up the settings

          Export settings

          Downloads every setting on this page as a file. The Wi-Fi network and the uploaded pictures are not part of it.

          The file is checked like any other change: values that do not make sense are ignored.

          Full backup

          The backup file contains your Wi-Fi password (and the web password if you set one), in clear text. Keep it private and never share it.
          Download backup

          Not available in rescue mode: the hotspot is open. Connect the device to your Wi-Fi first.

          One .tar file with every file stored on the device (settings, pictures, GIFs and the stock firmware's own files) and the Wi-Fi network. Plain tar: any archive tool opens it. The download takes a few seconds, during which the screen and the page wait.

          Only a backup made by this page is accepted. Every file in it is written back over the current one (the stock firmware's files included), the Wi-Fi network is replaced, and the device reboots. A file that does not fit is skipped. Nothing is deleted: files that are not in the backup stay.

          Device

          Factory reset puts every setting back to its default. Uploaded pictures and the Wi-Fi network are kept.
